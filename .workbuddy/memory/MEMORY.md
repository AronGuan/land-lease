# 项目长期约定（国有土地租赁）

## 协作偏好
- **改完不要用真实 Chrome 浏览器验证，用户会自己手动验证。** 交付以「代码改动 + 构建通过（npm run build）+ 必要的接口/数据断言」为准；不要主动跑浏览器截图/交互复验，除非用户明确要求。
- 用户偏好**小改动**：对齐原型时只补关键缺失点，不做大重构、不改整体结构。
- 沟通简洁、结构化（表格 / checklist），末尾给一句话核心结论。

## 前端约定
- 路由分组与页内 Tab：6 组导航（工作台 / 合同治理 / 收缴管理 / 宗地台账 / 统计报表 / 系统管理）。每页 `TABS` 数组定义组内 Tab，**默认路由必须等于首个 Tab**，否则用 `<Navigate to={首个Tab} replace />` 重定向（不能只渲染组件，否则 URL 停在组路径，PageHead 前缀兜底会错高亮）。
- 当前默认路由：`/contract → /contract/batch`（批次导入，业务流程 导入→复核→问题清单）。
- 核算基准日固定 `2026-09-30`，口径 v1.2；演示数据为练习集样例，顶栏有提示条。

## 数据与演示
- 练习集：50 合同 / 30 宗地 / 618 应缴 / 413 缴费 / 72 问题 / 1350 字段抽取；自动通过 35 : 人工复核 15。
- 合同结束日期集中在 2007–2020 及 2032/2033，**2026 全年仅 2 条到期（2026-04、2026-06）** → 到期日历按「最近有事件月份」自动定位，无事件月份显示空态提示。
- 原型 HTML 在项目根 `系统原型.html`（16 个 section）；需 HTTP 访问时拷到 `frontend/public/prototype.html` 由 Vite 提供（浏览器插件不认 file://）。

## 环境 / 工具
- 后端 uvicorn 8000、前端 vite 5173（`server.host` 固定 127.0.0.1，否则 curl 127.0.0.1 报 000）。后台任务易随中断被杀，用前先 curl 探活。
- 浏览器插件：`mcp__browser__*`，Chrome 的 browser_id **每次会话会变**（曾为 2、5），用前先 `browsers_list`。
- 一键预检：`scripts/drill_check.py`（9 项，含接口冒烟 28、核算 618/618 与 92/92、三套单测）。
