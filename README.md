# 国有土地租赁智能管理系统

> FDE 订单黑客松 · 国有土地租赁智能管理赛题
> AI 只读字段，**金额全部由纯规则引擎计算**，每个数字可追溯。

## 快速开始（3 条命令）

```bash
cp .env.example .env          # 填 DB_PASSWORD + DASHSCOPE_API_KEY
python scripts/seed.py --clear --force      # 灌演示数据（dataset_80: 40 合同 / 26 宗地 / 526 应缴；test_20 的 10 份留给手动治理）
python scripts/drill_check.py              # 预检 9 项（服务/数据/接口/核算/单测）
```

后端：`uvicorn landlease.app.main:app --port 8000`　前端：`cd frontend && npm run dev`

## 三条核心设计

**1. 三级识别，不吹准确率**
L1 直接识别（绿，可批量确认）／ L2 反推（黄，写推导链路，必须对照原件）／ L3 不可识别（红，留空 + 手工录入）。
涂改件、与登记冲突、关键字段低置信、存疑 → **整份强制转人工复核**。

**2. 金额与 AI 彻底隔离**
`calc.py` 是纯函数：输入合同要素 + 计租标准 + 缴费记录 + 减免登记，输出逐年应缴/实缴/欠缴。
无任何模型调用。舍入口径对齐标准答案生成器（float64 链 + Python round），每条核算落 `rent_calc_trace`。

**3. 「自动通过」≠ 跳过人工**
76% 批量确认（几秒/份，但必须先看最低置信度 Top3 预警）+ 24% 逐项复核 ≈ 2 人 5.5 天，替代 26 人天全量复核。

## 已知边界

- 无登录鉴权（比赛演示够用；`sys_user` 已预留，生产需接统一身份认证）
- 识别同步执行（3,000 份需改异步任务队列 + 进度推送）
- 原件存本地磁盘（生产迁对象存储）
- 「存疑待确认」按应缴最少暂算，差额已记入问题清单，**待主管部门书面确认后重算**
