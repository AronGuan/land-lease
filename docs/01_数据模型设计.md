# 国有土地租赁智能管理 · 数据模型设计 v1.0

> 依据：赛题需求说明（表 2 一期建设内容 / 表 3 合同与缴费要素 / 第七节评审）、练习集 06_计租标准与核算口径.docx、08_标准答案 CSV 列名、score.py 评分公式。
> 目标库：MySQL 8.0；字符集 utf8mb4；所有金额 DECIMAL(14,2)；所有金额计算用 Python Decimal，禁用 float。

## 一、设计原则（六条）

| # | 原则 | 落地方式 |
|---|---|---|
| 1 | **批次为骨架** | 一切导入数据挂 `import_batch`，撤回 = 按 batch 级联回滚 + 重算，支撑现场补档 40 分 |
| 2 | **字段级可追溯** | 每个抽取字段单独落 `field_extraction`，存 AI 值/最终值/置信度/来源/反推原因，支撑"全字段可人工修正"与审计 |
| 3 | **计算与证据分离** | 核算结果落 `rent_due`，推导过程落 `rent_calc_trace`；租金由规则程序算，AI 不参与 |
| 4 | **原件不入库** | 图片存磁盘 `storage/{batch}/{档案号}/页序.jpg`，库存相对路径 + SHA256 |
| 5 | **结果可导出** | 表结构与标准答案 CSV 列名一一映射，`export` 直接生成 合同要素/宗地台账/问题清单 三个 CSV |
| 6 | **只增不改** | `audit_log` append-only；核算口径、模板、阈值全部可配置（第八节要求留配置空间） |

## 二、表分层（24 张表）

```
接入层   import_batch · file_object
合同层   contract_doc · field_extraction · field_correction
宗地层   parcel · parcel_doc · registry_parcel · registry_street_level
规则层   rent_standard · reduction_record
核算层   rent_due · rent_calc_trace
缴费层   payment_record · payment_alloc
问题层   issue · issue_type(字典)
催缴层   collection_notice · sms_task · payment_track
税务层   tax_push · tax_push_item
支撑层   sys_user · audit_log · model_config · model_call_log · config_item · backup_record
```

## 三、核心表结构（关键字段）

## 四、评分对齐（score.py 反推的表设计要点）

| score.py 计分项 | 依赖表 | 表设计对应 |
|---|---|---|
| 合同要素 30 分（自动通过且对 +1 / 错 −1 / 复核 +0.5）| contract_doc + field_extraction | `process_type` 由**关键字段全对**的置信度阈值决定，阈值存 config_item，可调 |
| 宗地归集与登记匹配 15 分（多份文件归集 F1 + 不动产单元号）| parcel + parcel_doc | 宗地键 = 最新一份新签或续期合同的档案号；旧地号→单元号映射规则落第十条 |
| 租金核算 30 分（欠缴/累计应缴/2026 应缴，误差 0.01 元）| rent_due + rent_calc_trace | 全部 DECIMAL(14,2) + Decimal 计算，杜绝浮点误差 |
| 问题清单 20 分（13 类 F1 + 存疑单算 5 分）| issue | issue_type 字典严格 13 项，存疑项带 temp_algorithm + diff_amount |
| 催缴对象 5 分 | parcel.dunning_target | 第九条：登记权利人优先，查不到取最新合同承租人；电话优先登记 |

## 六、核算规则落点（口径 → 代码模块）

| 口径条款 | 落点 |
|---|---|
| 三、缴费年度与计费月数（起租/终止当月均计入，年度应缴 = 适用年租金 × 月数 ÷ 12）| `calc.monthly_prorate()` |
| 四(一) 固定 / 大小写不一致暂按大写 | `calc.applied_rent()` + 记 issue |
| 四(二) 随基准地价调整（面积 × 当年 1 月 1 日有效标准）| `calc.applied_rent()` 查 rent_standard |
| 四(三) 面积与登记不一致暂按合同面积 | 记 issue |
| 四(四) 涂改有签章按涂改后；无签章按第十二条存疑 | `doc.parse()` + issue |
| 五、续期与到期（期满未续按最后合同继续计收至 2026）| `calc.timeline()` |
| 六、减免（先算应缴 × (1−比例)）| `calc.reduction()` |
| 七、实缴归集（重复票据去重、按日期票据序、注明年度归该年、未注明冲最早欠缴年）| `alloc.allocate()` |
| 八、欠缴 = 应缴和 − 实缴和（含多缴，负数为多缴）| `calc.arrears()` |
| 九、催缴对象与电话优先级 | `dunning.resolve()` |
| 十、旧地号 ↔ 28 位单元号映射（第 7-9/10-12/15-…位）| `match.unit_no()` |
| 十二、存疑按应缴最少算法暂算 | `calc.ambiguous()` |
